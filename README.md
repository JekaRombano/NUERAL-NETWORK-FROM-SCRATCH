# NUERAL-NETWORK-FROM-SCRATCH
A neural network built from scratch in Python using NumPy and Pandas, without TensorFlow or PyTorch. The model uses Glucose and Insulin as input features and implements Min-Max normalization, ReLU and Sigmoid activation functions, Binary Cross-Entropy loss, manual backpropagation, and gradient descent.

### Architecture

* Input: Glucose, Insulin
* Hidden Layer: 4 neurons with ReLU
* Output Layer: 1 neuron with Sigmoid
* Training: 4,000 epochs
* Learning Rate: 0.001

### Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn

This project is designed to demonstrate the fundamental mechanics of neural networks and how models learn through forward propagation, loss calculation, backpropagation, and parameter optimization.
